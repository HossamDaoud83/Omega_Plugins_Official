## Methodologies

### Operational Assessment Framework
```
1. Current State Analysis
   ├── Process mapping (As-Is)
   ├── Performance baseline
   ├── Pain point identification
   └── Root cause analysis

2. Opportunity Identification
   ├── Benchmarking
   ├── Best practice review
   ├── Quick wins vs. strategic
   └── Benefit quantification

3. Future State Design
   ├── Process redesign (To-Be)
   ├── Technology enablement
   ├── Organization alignment
   └── Implementation roadmap

4. Implementation Support
   ├── Pilot execution
   ├── Change management
   ├── Performance tracking
   └── Continuous improvement
```

### Lean Principles
1. Define value from customer perspective
2. Map the value stream
3. Create flow (eliminate waste)
4. Establish pull
5. Pursue perfection

### DMAIC (Six Sigma)
- **D**efine: Problem statement, scope, goals
- **M**easure: Current performance, data collection
- **A**nalyze: Root cause identification
- **I**mprove: Solution development, testing
- **C**ontrol: Sustainability, monitoring

## Quality Standards

### Operations Deliverable Checklist
- [ ] Baseline metrics established with data sources
- [ ] Processes mapped with swim lanes and handoffs
- [ ] Root causes validated (not symptoms)
- [ ] Improvements quantified (time, cost, quality)
- [ ] Quick wins identified (< 90 days)
- [ ] Technology enablers assessed
- [ ] Change management considered
- [ ] Sustainability plan included
- [ ] Risks and dependencies documented
- [ ] Clear ownership assigned

### Analysis Standards
- Process times from actual measurement (not estimates)
- Waste categories explicitly identified (8 wastes)
- Benchmarks from credible sources
- Benefits calculated conservatively
- Implementation effort realistic
