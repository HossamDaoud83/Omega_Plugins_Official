# Consulting Frameworks

Apply core consulting methodologies and analysis frameworks.

## What This Does

Provides structured approaches for:
- Problem analysis (MECE, Issue Trees)
- Strategic analysis (SWOT, Porter's Five Forces, PESTEL)
- Communication (Pyramid Principle)
- Recommendations (structured format)
- Prioritization and gap analysis

## Instructions for Claude

When this skill is invoked:

1. **Ask User What Framework Needed**
   - Problem structuring (Issue Tree, MECE)
   - Strategic analysis (SWOT, Porter's 5 Forces, PESTEL)
   - Recommendation format
   - Gap analysis
   - Prioritization matrix
   - Root cause analysis (5 Whys)

2. **Apply Selected Framework**

   **Pyramid Principle (Communication)**
   - Lead with the answer
   - Group supporting arguments (3-5 key points)
   - Provide evidence for each
   - Address counterarguments
   - Clear next steps

   **MECE Analysis**
   - Ensure categories don't overlap (mutually exclusive)
   - Cover all possibilities (collectively exhaustive)
   - Common structures: Internal/External, People/Process/Technology

   **Issue Tree (Problem Decomposition)**
   - Break down core question hierarchically
   - Ensure MECE at each level
   - Lead to specific analyses

   **SWOT Analysis**
   - Internal: Strengths, Weaknesses
   - External: Opportunities, Threats
   - Format as 2×2 matrix

   **Porter's Five Forces**
   - Threat of new entrants
   - Bargaining power of suppliers
   - Bargaining power of buyers
   - Threat of substitutes
   - Competitive rivalry

   **Gap Analysis**
   - Current state
   - Target state
   - Gap identification
   - Priority ranking
   - Action plans

   **Recommendation Format**
   ```
   RECOMMENDATION: [Clear action]

   RATIONALE: [Why this approach]

   IMPACT:
   • [Quantified benefits]

   REQUIREMENTS:
   • Investment, Timeline, Dependencies

   RISKS & MITIGATIONS:
   • [Risk]: [Mitigation]

   NEXT STEPS:
   1. [Action] - [Owner] - [Date]
   ```

3. **Apply to Current Work**
   - Use framework to structure deliverable
   - Ensure quality standards met
   - Check MECE where applicable
   - Pyramid structure for all communications

4. **Quality Check**
   - [ ] Pyramid structure applied
   - [ ] MECE categories used
   - [ ] Evidence supports assertions
   - [ ] Clear next steps with owners
   - [ ] Professional formatting

## Core Frameworks Reference

### Pyramid Principle
1. Lead with answer
2. Group arguments (3-5 points)
3. Provide evidence
4. Address objections
5. Call to action

### MECE
Categories must be:
- Mutually Exclusive (no overlap)
- Collectively Exhaustive (cover everything)

### Issue Tree
```
Core Question
├── Sub-question 1
│   ├── Analysis 1.1
│   └── Analysis 1.2
├── Sub-question 2
└── Sub-question 3
```

### Executive Summary (SCR)
- **Situation:** Context
- **Complication:** Problem
- **Resolution:** Recommendation
