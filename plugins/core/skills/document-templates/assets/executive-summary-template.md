# Executive Summary Template

## Document Properties
- **Format:** Single page
- **Use:** Opening page of major deliverables
- **Output:** Include in Word document or PowerPoint

---

## Template Structure

```
═══════════════════════════════════════════════════════════════════════════════
                              EXECUTIVE SUMMARY
═══════════════════════════════════════════════════════════════════════════════

SITUATION
[1-2 sentences describing the context and background]

───────────────────────────────────────────────────────────────────────────────

COMPLICATION
[1-2 sentences describing the problem, challenge, or opportunity]

───────────────────────────────────────────────────────────────────────────────

RESOLUTION
[2-3 sentences stating the recommendation and expected outcome]

───────────────────────────────────────────────────────────────────────────────

KEY FINDINGS

• [Finding 1 - most important insight]

• [Finding 2 - supporting insight]

• [Finding 3 - supporting insight]

• [Finding 4 - if applicable]

• [Finding 5 - if applicable]

───────────────────────────────────────────────────────────────────────────────

NEXT STEPS

1. [Immediate action] - [Owner] - [Timeline]

2. [Follow-up action] - [Owner] - [Timeline]

3. [Subsequent action] - [Owner] - [Timeline]

═══════════════════════════════════════════════════════════════════════════════
```

---

## Writing Guidelines

### Situation
- State the engagement context
- Reference the client's strategic objectives
- Keep factual and objective

### Complication
- Identify the core problem or opportunity
- Create urgency without alarm
- Connect to business impact

### Resolution
- Lead with the recommendation
- State expected benefits
- Be specific and actionable

### Key Findings
- Limit to 3-5 bullets
- Each finding should be self-contained
- Quantify where possible
- Order by importance

### Next Steps
- Include owner for accountability
- Include timeline for urgency
- Make each step discrete and actionable
