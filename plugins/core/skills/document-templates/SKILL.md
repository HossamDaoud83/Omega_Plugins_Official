# Document Templates

Load standard consulting document templates and formatting guidelines.

## What This Does

Provides pre-structured templates for:
- Executive summaries
- Assessment reports
- Gap analysis documents
- Business cases
- Roadmaps
- Recommendations reports
- Status reports
- Steering committee presentations

## Instructions for Claude

When this skill is invoked:

1. **Ask User Template Needed**
   - Executive Summary (1 page)
   - Assessment Report (15-25 pages)
   - Gap Analysis (10-20 pages)
   - Business Case (10-15 pages)
   - Roadmap (15-25 pages)
   - Recommendations Report (12-20 pages)
   - Interview Summary (8-15 pages)
   - Status Report (2-3 pages)
   - Steering Committee Presentation (8-12 slides)

2. **Load Template Structure**
   - Provide section headings
   - Include subsections
   - Add guidance for each section
   - Include quality checklist

3. **Customize for Engagement**
   - Use client name
   - Use engagement reference
   - Add engagement-specific context
   - Adjust sections if needed

4. **Apply Omega Standards**
   - Pyramid principle (answer first)
   - Professional formatting
   - Omega branding
   - File naming convention

## Overview

Provides standardized templates for consulting deliverables ensuring consistent quality and professional presentation.

## Deliverable Types

### Executive Summary
**Use:** Opening page of major deliverables
**Length:** 1 page maximum

**Structure:**
1. **Situation** (1-2 sentences) - Context
2. **Complication** (1-2 sentences) - Problem/opportunity
3. **Resolution** (2-3 sentences) - Recommendation
4. **Key Findings** (3-5 bullets) - Critical insights
5. **Next Steps** (2-3 bullets) - Immediate actions

---

### Assessment Report
**Use:** Current state analysis, maturity assessments
**Length:** 15-25 pages

**Structure:**
1. Executive Summary
2. Methodology
3. Assessment Framework
4. Findings by Dimension
   - Current State
   - Gaps Identified
   - Evidence
5. Maturity Scores (if applicable)
6. Prioritized Recommendations
7. Appendix: Detailed Findings

---

### Gap Analysis Document
**Use:** Current vs future state comparison
**Length:** 10-20 pages

**Structure:**
1. Executive Summary
2. Scope and Methodology
3. Current State Summary
4. Future State Definition
5. Gap Analysis by Area
   - Gap Description
   - Impact
   - Priority
   - Recommended Actions
6. Prioritization Matrix
7. Implementation Roadmap
8. Appendix: Detailed Analysis

---

### Business Case
**Use:** Investment justification
**Length:** 10-15 pages

**Structure:**
1. Executive Summary
2. Problem Statement
3. Strategic Alignment
4. Options Considered
5. Recommended Solution
6. Financial Analysis
   - Costs (one-time, recurring)
   - Benefits (quantified)
   - NPV/ROI/Payback
7. Risk Assessment
8. Implementation Approach
9. Success Metrics
10. Appendix: Assumptions, Calculations

---

### Roadmap Document
**Use:** Implementation planning
**Length:** 15-25 pages

**Structure:**
1. Executive Summary
2. Vision and Objectives
3. Current State Summary
4. Target State
5. Roadmap Overview (Visual)
6. Phase Details
   - Scope
   - Key Deliverables
   - Timeline
   - Resources
   - Dependencies
7. Quick Wins
8. Risk Management
9. Governance
10. Success Metrics

---

### Recommendations Report
**Use:** Strategy/options presentation
**Length:** 12-20 pages

**Structure:**
1. Executive Summary
2. Context and Objectives
3. Methodology
4. Key Findings
5. Options Analysis
   - Option Description
   - Pros/Cons
   - Financial Impact
   - Risk Assessment
6. Recommendation
7. Implementation Approach
8. Next Steps

---

### Interview Summary
**Use:** Stakeholder interview synthesis
**Length:** 8-15 pages

**Structure:**
1. Executive Summary
2. Interview Methodology
3. Participants Overview
4. Key Themes
   - Theme Description
   - Supporting Quotes
   - Frequency
5. Pain Points (Prioritized)
6. Success Criteria Identified
7. Quick Win Opportunities
8. Appendix: Individual Summaries

---

### Status Report
**Use:** Weekly/bi-weekly updates
**Length:** 2-3 pages

**Structure:**
1. Executive Summary (3 sentences)
2. Progress Summary (table)
3. Key Accomplishments
4. Upcoming Activities
5. Risks and Issues
6. Decisions Required
7. Next Steps

---

### Steering Committee Presentation
**Use:** Executive updates
**Length:** 8-12 slides

**Structure:**
1. Agenda
2. Executive Summary (1 slide)
3. Progress Dashboard
4. Key Accomplishments
5. Key Findings/Insights
6. Risks and Issues
7. Decisions Required
8. Next Steps
9. Appendix

---

## Formatting Standards

### Text Formatting
| Element | Standard |
|---------|----------|
| Headers | Bold, sentence case |
| Body (documents) | 11pt |
| Body (presentations) | 18-24pt |
| Bullets | Maximum 3 levels |
| Line spacing | 1.15 |

### Visual Elements
| Element | Use When |
|---------|----------|
| Tables | Comparisons, data grids |
| Charts | Trends, distributions |
| Diagrams | Processes, relationships |
| Icons | Status indicators |

### Page Layout
| Element | Standard |
|---------|----------|
| Margins | 1 inch |
| Header | Document title, date |
| Footer | Page number, confidentiality |
| Logo | Top right corner |

## Quality Checklist

Before finalizing any document:
- [ ] Executive summary complete and compelling
- [ ] Pyramid principle followed (answer first)
- [ ] Evidence supports all claims
- [ ] Recommendations are actionable
- [ ] Next steps are clear with owners
- [ ] Formatting is consistent throughout
- [ ] Spelling and grammar checked
- [ ] Client names and data correct
- [ ] Confidentiality notice included
- [ ] Version number updated
- [ ] File named per convention

## File Naming Convention

```
[Client]_[Deliverable]_[Version]_[Date].[ext]

Examples:
Acme_CurrentStateAssessment_v1.0_2024-12-20.docx
GlobalBank_DigitalRoadmap_v2.1_2024-12-22.pptx
HealthCo_BusinessCase_DRAFT_2024-12-18.docx
```
