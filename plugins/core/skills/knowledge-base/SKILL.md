# Knowledge Base Management Skill

## Description

Search and save to organizational knowledge base.

## Available Commands

```
/kb-search          - Search organizational knowledge base
/kb-save            - Save content to knowledge base
```

## Instructions for Claude

### When user invokes `/kb-search`

See [references/kb-search.md](references/kb-search.md) for detailed instructions.

1. Search knowledge base for:
   - Similar engagements
   - Best practices
   - Templates
   - Lessons learned
   - Industry insights
2. Return relevant results with context

### When user invokes `/kb-save`

See [references/kb-save.md](references/kb-save.md) for detailed instructions.

1. Save valuable content to KB:
   - Deliverables
   - Insights
   - Lessons learned
   - Templates
   - Analysis frameworks
2. Tag appropriately for future retrieval
