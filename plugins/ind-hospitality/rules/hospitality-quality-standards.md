# Hospitality (HOSPITALITY) — Quality Standards

Omega capability-specific quality criteria for `omega-hospitality` deliverables. Loaded automatically when this plugin is installed.

## Always required

- Pyramid Principle structure (recommendation first, then evidence)
- MECE analysis (Mutually Exclusive, Collectively Exhaustive)
- Omega branding (colors, fonts, logo per `assets/omega-branding.json`)
- Source citations on all data points
- Recommendation Format used in any advice section

## Capability-specific

- RevPAR analysis decomposes ADR × occupancy × segment mix
- F&B review cites cost-of-sales %, labor %, and guest satisfaction
- Brand audit links each gap to a specific brand standard clause
- Guest experience interventions ranked by impact × effort

See the `hospitality` skill SKILL.md per-skill "Quality checklist" sections for command-specific criteria.

## Hand-off

Log surprising findings as instinct candidates for `/omega:learn` (mark `visibility: sanitizable` so they can sync to the central brain after sanitization).
