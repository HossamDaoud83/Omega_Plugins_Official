# Logistics & 3PL (LOGISTICS) — Quality Standards

Omega capability-specific quality criteria for `omega-logistics` deliverables. Loaded automatically when this plugin is installed.

## Always required

- Pyramid Principle structure (recommendation first, then evidence)
- MECE analysis (Mutually Exclusive, Collectively Exhaustive)
- Omega branding (colors, fonts, logo per `assets/omega-branding.json`)
- Source citations on all data points
- Recommendation Format used in any advice section

## Capability-specific

- Fleet recommendations consider TCO (acquisition, fuel, maintenance, driver, insurance)
- Warehouse designs include slotting strategy and labor model
- Last-mile strategy quantifies cost per delivery by network choice
- Mode-mix decisions cite CO2e per ton-km alongside cost

See the `logistics` skill SKILL.md per-skill "Quality checklist" sections for command-specific criteria.

## Hand-off

Log surprising findings as instinct candidates for `/omega:learn` (mark `visibility: sanitizable` so they can sync to the central brain after sanitization).
