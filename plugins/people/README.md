# omega-people

Org design, talent strategy, change management, culture transformation, workforce planning.

## Slash commands

| Command | Purpose |
|---|---|
| `/omega-people:org-design` | Design target operating model and organization structure. |
| `/omega-people:change-mgmt` | Develop change-management plan using ADKAR / Prosci. |
| `/omega-people:workforce-plan` | Build skill-based workforce plan with gap analysis and reskilling roadmap. |
| `/omega-people:culture-assess` | Diagnose organizational culture using validated instrument; identify levers. |
| `/omega-people:talent-strategy` | Define talent strategy: attract, develop, retain across critical roles. |

## Skills

- `people` — People & Organization methods (see `skills/people/SKILL.md`)

## Subagents

- `org-design-lead` — Org Design Lead
- `change-leader` — Change Leader

## Quality gate

`rules/people-quality-standards.md` is loaded automatically by `quality-gate.js` when this plugin is installed.

## Install

```
/plugin install omega-people@omega-plugins
```

Usually paired with `omega-core` and one industry plugin.
