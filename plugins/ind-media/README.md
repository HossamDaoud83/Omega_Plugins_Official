# omega-ind-media

Media & entertainment — content economics, streaming, rights management, ad tech.

## Slash commands

| Command | Purpose |
|---|---|
| `/omega-media:content-econ` | Model content economics: cost per hour, viewing share, unit economics. |
| `/omega-media:streaming-strategy` | Design streaming strategy: D2C, content mix, monetization model. |
| `/omega-media:rights-strategy` | Strategize rights acquisition / licensing across windows and territories. |
| `/omega-media:adtech-stack` | Review ad tech stack (DSP, SSP, DMP, CDP) and identify rationalization opportunities. |

## Skills

- `media` — Media & Entertainment methods (see `skills/media/SKILL.md`)

## Subagents

- `media-strategist` — Media Strategist

## Quality gate

`rules/media-quality-standards.md` is loaded automatically by `quality-gate.js` when this plugin is installed.

## Install

```
/plugin install omega-ind-media@omega-plugins
```

Usually paired with `omega-core` and one industry plugin.
