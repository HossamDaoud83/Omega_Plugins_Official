# Mining & Metals (MINING) — Quality Standards

Omega capability-specific quality criteria for `omega-mining` deliverables. Loaded automatically when this plugin is installed.

## Always required

- Pyramid Principle structure (recommendation first, then evidence)
- MECE analysis (Mutually Exclusive, Collectively Exhaustive)
- Omega branding (colors, fonts, logo per `assets/omega-branding.json`)
- Source citations on all data points
- Recommendation Format used in any advice section

## Capability-specific

- Reserves classified per JORC / NI 43-101 with QP sign-off
- Tailings recommendations cite GISTM principles explicitly
- Social license analysis maps stakeholder map + grievance log
- ESG analysis covers water, biodiversity, community, climate transition

See the `mining` skill SKILL.md per-skill "Quality checklist" sections for command-specific criteria.

## Hand-off

Log surprising findings as instinct candidates for `/omega:learn` (mark `visibility: sanitizable` so they can sync to the central brain after sanitization).
