# ESG & Sustainability (ESG) — Quality Standards

Omega capability-specific quality criteria for `omega-esg` deliverables. Loaded automatically when this plugin is installed.

## Always required

- Pyramid Principle structure (recommendation first, then evidence)
- MECE analysis (Mutually Exclusive, Collectively Exhaustive)
- Omega branding (colors, fonts, logo per `assets/omega-branding.json`)
- Source citations on all data points
- Recommendation Format used in any advice section

## Capability-specific

- Every emission figure cites methodology (location-based vs market-based, emission factor source, year)
- Materiality assessment includes ≥10 stakeholder groups and double-materiality lens
- Net-zero pathway is SBTi-aligned (1.5°C trajectory, near-term + long-term targets)
- CSRD gap analysis maps to ESRS topical standards (E1-E5, S1-S4, G1)

See the `esg` skill SKILL.md per-skill "Quality checklist" sections for command-specific criteria.
