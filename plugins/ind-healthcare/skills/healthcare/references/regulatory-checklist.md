# Healthcare Regulatory Compliance Checklist

## HIPAA Privacy Rule

### Administrative Requirements
- [ ] Privacy Officer designated
- [ ] Privacy policies and procedures documented
- [ ] Workforce training completed annually
- [ ] Business Associate Agreements in place
- [ ] Notice of Privacy Practices provided to patients
- [ ] Patient rights procedures established

### Patient Rights
- [ ] Access to PHI within 30 days
- [ ] Amendment requests process
- [ ] Accounting of disclosures
- [ ] Restriction requests handled
- [ ] Confidential communications

### Minimum Necessary
- [ ] Role-based access controls
- [ ] Policies limit PHI access to job requirements
- [ ] Routine disclosures have limits defined

---

## HIPAA Security Rule

### Administrative Safeguards
- [ ] Security Officer designated
- [ ] Risk analysis conducted (annual)
- [ ] Risk management plan implemented
- [ ] Sanction policy in place
- [ ] Information system activity review
- [ ] Workforce security procedures
- [ ] Security awareness training
- [ ] Incident response procedures
- [ ] Contingency plan (backup, disaster recovery, emergency mode)
- [ ] Business Associate oversight

### Physical Safeguards
- [ ] Facility access controls
- [ ] Workstation use policies
- [ ] Workstation security
- [ ] Device and media controls

### Technical Safeguards
- [ ] Access controls (unique user ID, emergency access, automatic logoff, encryption)
- [ ] Audit controls
- [ ] Integrity controls
- [ ] Transmission security (encryption in transit)
- [ ] Authentication

---

## HITECH Act

### Breach Notification
- [ ] Breach assessment process defined
- [ ] 60-day notification for breaches > 500 individuals
- [ ] Annual reporting for breaches < 500
- [ ] Media notification for large breaches
- [ ] Documentation of all breach assessments

### Business Associates
- [ ] Direct liability understood
- [ ] BAA requirements updated
- [ ] Subcontractor requirements

---

## 21st Century Cures Act

### Information Blocking
- [ ] No information blocking practices
- [ ] Exceptions documented if applicable
- [ ] APIs available for patient access
- [ ] EHI release processes defined

### Interoperability
- [ ] USCDI data elements supported
- [ ] FHIR APIs implemented
- [ ] Patient access APIs available
- [ ] Provider directory APIs available

---

## CMS Conditions of Participation

### Key Requirements
- [ ] Governing body requirements met
- [ ] Patient rights documented
- [ ] QAPI program in place
- [ ] Infection control program
- [ ] Discharge planning
- [ ] Emergency preparedness plan
- [ ] Medical staff credentialing
