# PMO & Program Delivery (PMO) — Quality Standards

Omega capability-specific quality criteria for `omega-pmo` deliverables. Loaded automatically when this plugin is installed.

## Always required

- Pyramid Principle structure (recommendation first, then evidence)
- MECE analysis (Mutually Exclusive, Collectively Exhaustive)
- Omega branding (colors, fonts, logo per `assets/omega-branding.json`)
- Source citations on all data points
- Recommendation Format used in any advice section

## Capability-specific

- Every program has a charter with objectives, governance, scope, and named sponsor
- RAID items have owner + due date + aging; nothing untouched > 14 days
- Status packs have a 3-bullet headline, decisions-needed section, and 2-week look-ahead
- Stage-gate reviews use a scorecard, not vibes

See the `pmo` skill SKILL.md per-skill "Quality checklist" sections for command-specific criteria.

## Hand-off

Log surprising findings as instinct candidates for `/omega:learn` (mark `visibility: sanitizable` so they can sync to the central brain after sanitization).
