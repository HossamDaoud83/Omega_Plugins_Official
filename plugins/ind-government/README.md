## Install

```
/plugin install @omega/ind-government
```

Requires `@omega/core`. Pair with the relevant service-line plugin (`@omega/aig`, `@omega/dig`, etc.) for full delivery capability.

## Purpose

Industry-domain context. Loaded so service-line agents can reference industry conventions, regulations, and benchmarks specific to government & public sector.
