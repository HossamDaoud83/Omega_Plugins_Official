# DSCR Thresholds

## Definition

**DSCR (Debt Service Coverage Ratio)** = CFADS / (Interest + Principal repayment) for the period.

Where CFADS = Cash Flow Available for Debt Service = EBITDA – Tax – Working Capital changes – CapEx (maintenance only after construction).

## Threshold ladder

| DSCR (yearly) | Interpretation | Banking action |
|---|---|---|
| ≥ 1.40x | Strong | Comfortable headroom; standard pricing |
| 1.30x – 1.40x | Healthy | Standard project finance covenant |
| 1.20x – 1.30x | Acceptable | Tightest typical lender covenant |
| 1.05x – 1.20x | Marginal | Cash sweep / dividend lock-up triggers |
| 1.00x – 1.05x | Critical | Distress; technical default risk |
| < 1.00x | Default | Cash insufficient to service debt |

## Reporting conventions

- Report **minimum DSCR** across loan tenor (worst single year)
- Report **average DSCR** across loan tenor
- Report **P80 minimum DSCR** (Monte Carlo) — must be ≥ 1.20x for typical covenants
- For BOT / PPP, also report **LLCR** (Loan Life Cover Ratio) and **PLCR** (Project Life)

## Common covenant package

| Covenant | Trigger |
|---|---|
| Min DSCR | < 1.20x → cash sweep |
| Avg DSCR | < 1.30x → cash sweep |
| Dividend lock-up | DSCR < 1.20x rolling 12-month |
| Technical default | DSCR < 1.00x |

## Mitigation if DSCR < target

1. Extend loan tenor (lowers annual debt service)
2. Reduce debt ratio (increase equity contribution)
3. Defer principal (interest-only period during ramp-up)
4. Sculpt debt repayment to project cash flow shape
5. Step-up tariff or take-or-pay revenue floor (reduces revenue uncertainty)
