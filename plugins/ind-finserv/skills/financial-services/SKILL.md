# Financial Services Industry Skill

## Overview

Provides financial services context for consulting engagements including regulatory frameworks, core systems, risk management, and industry considerations.

---

## Industry Characteristics

| Characteristic | Description |
|----------------|-------------|
| Regulatory Intensity | Heavily regulated, multiple supervisors |
| Risk Culture | Risk management embedded in operations |
| Data Sensitivity | PII, financial data, transaction records |
| Technology Dependency | Real-time processing, high availability |
| Competitive Dynamics | Traditional vs. fintech disruption |
| Trust Imperative | Reputation and customer trust critical |

## Regulatory Framework

### Banking Regulators (US)
| Regulator | Scope |
|-----------|-------|
| OCC | National banks |
| Federal Reserve | Bank holding companies, state member banks |
| FDIC | Deposit insurance, state non-member banks |
| CFPB | Consumer financial protection |
| State Regulators | State-chartered institutions |

### Securities & Investment
| Regulator | Scope |
|-----------|-------|
| SEC | Securities markets, investment advisers |
| FINRA | Broker-dealers |
| CFTC | Derivatives, commodities |
| State Securities | Blue sky laws |

### Insurance
- State insurance commissioners
- NAIC model regulations
- State guaranty associations

### Key Regulations
| Regulation | Focus |
|------------|-------|
| Basel III/IV | Capital requirements |
| Dodd-Frank | Systemic risk, consumer protection |
| BSA/AML | Anti-money laundering |
| GLBA | Privacy |
| SOX | Financial reporting controls |
| PCI-DSS | Payment card security |
