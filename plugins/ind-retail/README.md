# `@omega/ind-retail` — Retail Industry

Omnichannel, POS, inventory, customer.

## What this plugin provides

| Component | Count |
|---|---|
| Skills | 1 |
| Agents | 1 |

## Install

```
/plugin install @omega/ind-retail
```

Requires `@omega/core`. Pair with the relevant service-line plugin (`@omega/aig`, `@omega/dig`, etc.) for full delivery capability.

## Purpose

Industry-domain context. Loaded so service-line agents can reference industry conventions, regulations, and benchmarks specific to retail industry.
